# Verification Checklist & Getting Started

## ✅ Pre-Installation Verification

### Check You Have:
- [ ] Node.js installed (version 16+)
  - Test: `node --version`
- [ ] npm installed (usually comes with Node)
  - Test: `npm --version`
- [ ] The `newg-react` folder
- [ ] Original image files: `day.jpg`, `night.jpg`, `image (2).png`

## 📋 Installation Steps (Copy & Paste)

### Step 1: Navigate to Project
```bash
cd newg-react
```

### Step 2: Install Dependencies
```bash
npm install
```
**Wait for completion** (1-3 minutes)

### Step 3: Copy Image Files
Before running, copy these files to `newg-react/public/`:
- `day.jpg`
- `night.jpg`  
- `image (2).png`

### Step 4: Start Development
```bash
npm run dev
```

You should see:
```
VITE v5.0.8  ready in XXX ms

➜  Local:   http://localhost:5173/
➜  press h + enter to show help
```

**Browser opens automatically** ✅

## 🐛 Common Issues & Fixes

### Issue: Port 5173 already in use
**Fix:**
```bash
npm run dev -- --port 3000
```

### Issue: Images not showing
**Fix:**
1. Copy files to `public/` folder
2. Check filenames exactly match:
   - `day.jpg` (not day.JPG)
   - `night.jpg` (not night.JPG)
   - `image (2).png` (with space before 2)
3. Restart dev server: `npm run dev`

### Issue: "npm command not found"
**Fix:**
1. Install Node.js from nodejs.org
2. Close and reopen terminal
3. Try again

### Issue: White screen
**Fix:**
1. Press F12 to open Console
2. Check for error messages
3. Clear browser cache
4. Try incognito window

### Issue: Mobile menu not working
**Fix:**
1. Make sure window is <768px wide
2. Open DevTools (F12)
3. Click mobile device icon
4. Select iPhone or similar

### Issue: Theme not saving
**Fix:**
1. Check localStorage is enabled
2. Try different browser
3. Try incognito mode
